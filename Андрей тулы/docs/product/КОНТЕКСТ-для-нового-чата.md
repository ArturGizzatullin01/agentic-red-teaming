## Суть задачи
Сделать инструмент, который **автоматически атакует долговременную память ИИ-агента** и доказывает находки. Мишень — готовый стенд `genai-invest-agent-memory-stand` (инвест-ассистент с памятью, локальный Docker).
Фокус (по кейсодателю Тимуру Низамову): **только атаки на память** (динамика, не статика); **разнообразие атак важнее глубины**; ASR считаем сами; killer-фича — кастомизация/подгрузка своих атак.
Самое критичное последствие для банка: **Broken Access Control** (утечка чужих данных/банковской тайны через память), затем утечка конкурентам, затем hijack.

## Где мы сейчас (03.09 вечер)
- Инструмент работает end-to-end на живом стенде: ядро (доставка→память→судья→отчёт), 4 attack-пака, «атака = один файл».
- **Главная находка:** личная просьба клиента осела в глобальный слой памяти → стала «правилом для всех», вместе с чужими данными (ФИО/счёт/портфель). Это BAC — приоритет №1 банка.
- Модели: судья = DeepSeek v4 Flash (Yandex), атакующий = Qwen3.6-35B (Yandex), стенд/агент = локальная qwen2.5:3b. Судья ≠ атакующий (требование Тимура).
- Идёт/планируется 2-часовой стресс-тест: все паки × k=3 повтора, режимы vulnerable/protected, отчёт-таблица.
- Есть параллельный, более широкий инструмент другого агента (`memred`, 16 атак) — нужно свести с командой, что берём в защиту.
