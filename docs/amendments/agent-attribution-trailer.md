# Поправка конституции: атрибуция агентских коммитов (черновик)

**Created**: 2026-09-06. **Статус**: черновик к обсуждению; в этой передаче коммитов
и правок конституции нет ([аудит](../integration-handoff/audit.md), «Конституционные
границы»).

## Проблема

Конституция (раздел «Коммиты») требует трейлер
`Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>` в коммитах, сделанных с
участием агента. Интеграция выполняется исполнителями GLM 5.3 / GLM 5.3 Flash —
подписание их работы именем Claude некорректно и ломает атрибуцию аудита.

## Предлагаемая правка (PATCH до MINOR — решает команда)

Раздел «Коммиты», пункт о трейлере, заменить на:

```text
- Трейлер `Co-Authored-By: <имя исполнителя> <noreply@…>` — в коммитах, сделанных
  с участием агента; имя исполнителя фиксируется в задании (handoff/tasks). Для
  агентских исполнителей без почты использовать noreply-адрес вида
  `noreply@<executor>.local` (пример: `Co-Authored-By: GLM 5.3 Flash <noreply@g.local>`).
```

Тип версии: **PATCH** (уточнение формулировки, смена константы на правило), если
команда считает смену исполнителя уточнением; **MINOR** — если считать это новым
правилом атрибуции. Решение за ревью поправки, не за исполнителем интеграции.

## Порядок

1. Обсудить и влить поправку отдельным PR до первого коммита GLM.
2. До ратификации GLM-исполнители коммитов не делают (работа передаётся диффами и
   отчётами, как в этой передаче).
3. В коммит-теле правило `Проверено:` сохраняется без изменений.

## Основание

[Аудит](../integration-handoff/audit.md): «Конституция требует трейлер Claude Opus 5
даже для агентских коммитов. Для GLM это неверная атрибуция: подготовить отдельную
поправку до коммитов GLM».
