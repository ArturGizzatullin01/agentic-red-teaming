# Аудит исходных материалов

Дата проверки: 2026-09-06. Метод: чтение исходников обоих архивов и локального донора,
пересчёт `runs_asr/batch.jsonl`. Сеть, ключи и live-стенд не использовались.
Ниже обнаружения статического аудита; воспроизведение дефектов входит в задачи кодера.

## Критичные исправления исходного ТЗ

| ID | Основание в исходниках | Следствие и исправление |
|---|---|---|
| A01 | `core/runner.py`: `wait_until_persistent` раньше `close_session`; адаптер финализирует в `close_session` | Возможен ложный persistence=False. Зафиксировать тестом finalize → settle → новая trigger-сессия. |
| A02 | `oracles/base.py`: `source_user == attacker` и поиск всего payload | Глобальная запись без автора и пересказ суммаризатора могут не пройти WRITE. Нужны уникальная канарейка, diff и атрибуция текущего case. |
| A03 | Там же: `text in candidate.payload` | Пустой текст совпадёт с любым payload. Запретить пустые/слишком слабые свидетельства. |
| A04 | `oracles/external_effect.py`, `adoption.py`: поиск в `all_events` | Событие установки может выдать ложную активацию. Ограничить principal, session, phase; связать call/result. |
| A05 | Предложение T-4: глобальный snapshot как external_effect BAC | Snapshot доказывает запись/эскалацию, но не выдачу другому пользователю. Нужен ответ получателю либо его связанный tool_result. |
| A06 | `adoption.py` не имеет ветки `policy_evicted` | Добавить только external_effect недостаточно: adoption останется UNKNOWN и success=False. Нужны обе проверки и наблюдаемый эффект. |
| A07 | `adoption.py` и `external_effect.py` ищут маркер буквально | Нормализация нужна в обеих стадиях, в WRITE и settle; отказ с цитатой маркера не означает принятие правила. |
| A08 | `cli.py`: `--output` обязателен | Команда DoD из исходного ТЗ неполна. Каждому run/campaign задавать каталог результата. |
| A09 | `scripts/set_stand_target.py` меняет env, вызывает restart; sanity допускает пустой content | Смена конфигурации не доказана. Нужны пересоздание сервиса, проверка фактической конфигурации, rollback и ненулевой exit при пустом ответе. |
| A10 | `AttackBase.generate` sync, runner async; runtime attacker у команды не подключён | «generic OpenAI» — адаптер цели, не готовый генератор атак. Нельзя переносить async LLM-вызов внутрь sync generate. |
| A11 | Конституция II, VIII и SDD; текущие `expected_effect`, `params` — dict | Есть существующий долг типов. Не размножать его; инфраструктурное изменение контрактов выделить отдельно до attack-port. |
| A12 | DOCUMENT/TOOL_OUTPUT донора и `DeliveryStep.message` команды | Текст документа/ошибки в user message — эмуляция канала. Отмечать `effective_channel=user_message`; не заявлять настоящий перехват tool output. |

Пути `core/*`, `oracles/*` в A01–A08 относятся к `src/memnotsafe/` архива команды.
Путь в A09 относится к донору. Проверить A09 интеграционным тестом с поддельным
process runner до разрешённого локального запуска Docker.

## Конституционные границы

- Сохранить пять ролей и формулу success без изменений.
- Новые атаки не меняют `core/`; предварительные исправления runner и инфраструктура
  оформляются отдельными SDD-фичами с собственным обоснованием, не скрываются в порте.
- Если локальный `/speckit-plan` запрещает даже общую инфраструктурную правку ядра,
  оформить уточнение конституции отдельным PR до зависимой реализации.
- Новые межкомпонентные контракты — dataclass. Унаследованные словари мигрировать
  совместимым преобразованием на границе, а не переписывать всё приложение.
- Mock должен моделировать уязвимое и защищённое поведение. Smoke донора с фиктивным
  судьёй подтверждает загрузку паков, но не эксплуатацию.
- Сгенерированные runs/reports не коммитить. Историческое evidence не копировать
  бесконтрольно под новым именем: manifest и агрегат — в репозиторий, сырые данные —
  отдельно; маленькие очищенные regression fixtures допустимы как тестовые входы.
- Конституция требует трейлер Claude Opus 5 даже для агентских коммитов.
  Для GLM это неверная атрибуция: подготовить отдельную поправку до коммитов GLM.
  В этой передаче коммитов и изменений конституции нет.

## Что не доказано

Текущая модель работающего стенда, доступность провайдеров и endpoint, истинность
всех исторических findings, холодный старт новой сборки и повторение ASR не проверены.
Сведения handoff об успешных исследованиях сохраняются как заявления источника.
Закрытые исследования не переоткрывать без причины; расхождения с кодом проверять.

Схема из архива стенда читается в `app/memory/models.py`, `store.py`, `mongo.py`;
параметры запуска — в `app/config.py`, `docker-compose.yml`.
Адаптер команды определяет global по коллекции; знание Mongo должно оставаться там.
Отсутствие `user_id` само по себе не является универсальным правилом для других таргетов.
