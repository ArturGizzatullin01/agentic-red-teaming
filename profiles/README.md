# Профили агентов (`profiles/`)

> Версионируемый **вход** генерации корпуса атак (US1 фичи
> [004-llm-attack-generation](../specs/004-llm-attack-generation/spec.md)). Каждый файл —
> декларативное описание проверяемого агента: назначение, интерфейс, инструменты, модель памяти
> и признаки компрометации. Секретов не содержит (FR-016) — только имена сущностей и полей.

Схема и правила валидации:
[contracts/agent-profile.schema.md](../specs/004-llm-attack-generation/contracts/agent-profile.schema.md).

Профиль читается `generation/profile.py`. Отсутствие любой обязательной секции или пустой
`compromise.external_effect` → ошибка конфигурации (`exit 1`) до любых вызовов атакующей LLM.

Имя файла — ASCII (`profiles/<id>.yaml`), содержимое — русское (правила документации конституции).
