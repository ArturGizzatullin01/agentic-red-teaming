# Research: 005-cold-start-release

**Created**: 2026-09-06. Источники: [acceptance.md](../../docs/integration-handoff/acceptance.md),
[аудит](../../docs/integration-handoff/audit.md) (пересчёт истории), донорский опыт
холодного старта.

## Решения

1. **«Из коробки» = чистая установка, не старый smoke.** Донорский холодный старт
   (2026-09-05) проверялся на копии с реальными ключами и живым стендом рядом; здесь
   wheel ставится вне src-checkout, демо идёт на mock без ключей/сети/Docker.
2. **Историческая атрибуция.** Пересчёт донора: 128 строк, только 15 с парой
   attacker/target-тегов (все tool_error_echo); остальное — смешанные цели. Публикация
   как заявления источника; Wilson 95% в агрегате; без обещания совпасть с историей.
3. **Live-гигиена.** Отдельный compose-проект; reset только тестового стенда; restore
   по контракту 003; n>=5 флагманы, n>=10 cross-user/flood при демонстрации;
   execution error ≠ completed failure ≠ UNKNOWN ≠ composite success.
4. **Офлайн-граница демо.** Демо-сценарии не требуют Mongo extra (lенивый импорт
   адаптера); отчет/повтор — на файлах прогона; проверяется отсутствие абсолютных
   путей автора и секретов в поставке.
5. **Атрибуция коммитов.** До первого GLM-коммита требуется ратифицированная поправка
   конституции (трейлер исполнителя). Черновик готов:
   [docs/amendments/agent-attribution-trailer.md](../../docs/amendments/agent-attribution-trailer.md);
   в этой передаче коммитов нет.
